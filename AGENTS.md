# Repository Instructions

Follow [CONTRIBUTING.md](CONTRIBUTING.md) for contribution and validation guidance.

When generating commit messages, pull request titles, or pull request descriptions,
follow the **Commit and Pull Request Writing Style** section in CONTRIBUTING.md.
Use English imperative sentences for commit subjects and pull request titles, and
use [.github/pull_request_template.md](.github/pull_request_template.md) for pull
request descriptions.
